# ADR-002: Administrator-only access to benefactor reports

## Status

Accepted

## Date

2026-10-02

## Context

Benefactor reports summarize personal enrollment data. The operator explicitly specified that only administrators should see the new reports. The existing manual welcome-email action is also restricted to administrators.

## Decision

Only administrators may open or use the new benefactor reports. The existing administrator-only permission for manual welcome-email sends remains in place.

## Alternatives Considered

### Alternative 1: Let Secretariat staff view reports

- **Pros:** More staff can consult geographic totals.
- **Cons:** Broadens access beyond the operator's stated requirement.
- **Why rejected:** The operator chose administrator-only report visibility.

### Alternative 2: Let all authenticated staff view and send

- **Pros:** Fewer role distinctions in the interface.
- **Cons:** Grants manual sending and reporting access beyond the established administrative role.
- **Why rejected:** It conflicts with current authorization and the operator's report-access decision.

## Consequences

### Positive

- Report access is explicit and consistent with the requested scope.
- Manual welcome-email sends retain their existing administrative ownership.

### Negative

- Secretariat staff must ask an administrator for geographic report information.

### Risks

- Navigation alone cannot enforce the boundary; the implementation must protect report reads directly.
