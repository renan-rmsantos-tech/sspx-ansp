# ADR-007: Chart library with equivalent data tables

## Status

Accepted

## Date

2026-10-13

## Context

The PRD requires two visual charts and equivalent data tables. The project currently has no charting dependency.

## Decision

Add a maintained React chart library for the two administrator-only category charts. Feed it only aggregate counts. Render semantic HTML tables from the same data, and retain visible totals and categories when filters change.

## Alternatives Considered

### Alternative 1: Local HTML/CSS bars

- **Description**: Build simple bars without a package.
- **Pros**: Smaller dependency surface.
- **Cons**: More custom chart behavior and maintenance.
- **Why rejected**: The operator chose a library.

### Alternative 2: Tables only

- **Description**: Defer the charts.
- **Pros**: Accessible baseline with minimal code.
- **Cons**: Does not satisfy the two-chart requirement.
- **Why rejected**: The operator chose charts now.

## Consequences

### Positive

- The reports provide quick comparison and a precise, keyboard-readable table.

### Negative

- Adds client bundle weight and a dependency to maintain.

### Risks

- Chart-specific accessibility varies. Treat the table as the canonical accessible data representation and test mobile and keyboard behavior.

## Implementation Notes

Select the package during implementation based on React 19 and Next.js 16 compatibility. Avoid passing donor-level data to the chart component.
