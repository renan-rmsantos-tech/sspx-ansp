Superfícies aplicadas

Este card carrega os arquivos de origem preservados na raiz do projeto — não recriações. Cada quadro abaixo é o HTML real do projeto ASNP rodando dentro de um iframe em escala reduzida.

Nota de fidelidade. Os iframes exigem que a pasta seja servida (o painel de arquivos do Open Design já faz isso). O console de administração checa localStorage.bolsa_auth e redireciona para o login — esta página seta essa flag antes de carregar, apenas para a revisão. O rodapé de index.html aponta para mqjmgzod-logo.png (marca da FSSPX), que não veio no pacote de evidências; a imagem aparece quebrada e está registrada como lacuna em context/provenance.md.
