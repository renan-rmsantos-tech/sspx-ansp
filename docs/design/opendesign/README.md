# Open Design — protótipos de referência

Exportações estáticas geradas no **Open Design**. Servem como referência visual e de fluxo; o código de produção vive em `app/`.

| Arquivo | Superfície |
|---------|------------|
| `index.html` | Landing institucional |
| `formulario.html` | Formulário de bolsa (multi-etapas) |
| `admin.html` | Painel administrativo |
| `login.html` | Login do admin |
| `design-system.html` | Tokens, tipografia e componentes |

Assets de imagem (`logo-gesso.jpg`, `base1.png`, `base2.png`, etc.) ficam nesta mesma pasta.

Para abrir localmente, sirva os arquivos com um servidor estático ou abra diretamente no navegador (alguns recursos podem exigir servidor por CORS de fontes/imagens).
